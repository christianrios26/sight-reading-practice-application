# Sight Reading Practice Application
The application generates sheet music for a beginner pianist to play along to and practice sight-reading. Originally a student-proposed project for the Software Engineering (CEN4010) undergraduate course.
## Running the Application
This project was developed using the Eclipse IDE. Simply download the source code .zip file, and place the "sight-reading-practice-application" directory within it into the "eclipse-workspace" directory on your device that all Eclipse project directories are contained within. Then, from within Eclipse, import the project (File -> Import -> Existing Projects into Workspace -> Under "Select root directory", browse for the project directory that was placed in the "eclipse-workspace" directory).
As of right now, the repository cannot be easily cloned. This will be updated in the future.

## About the Application
The application aims to solve a problem for learners of the piano. Sight-reading is the act of playing an instrument according to sheet music that the player has never seen or practiced beforehand. Without a teacher, it can be difficult for beginner pianists to learn how to sight-read. Learning how to sight-read is important for pianists as it allows them to learn musical pieces faster and play music without memorizing. Really, sight-reading is an important component of musical proficiency for any instrument player. However, not all pianists have access to music teachers to help them develop the skill and provide the feedback they need to improve. This problem of feedback is what our application aims to solve.

As a black box, the solution starts with generating random lines of sheet music (realistic to what a pianist might see in practice) and detecting inputs from a digital piano connected to a computer. As a pianist tries to play according to the sheet music, the software gives visual feedback by changing the colors of notes on the page. After the pianist finishes playing the passage, accuracy scores based on rhythm and pitch are displayed for additional feedback.

## Use Details
The application has three main screens: a title screen, an instructions screen, and a practice screen (the practice screen is the main screen). The application is intended to be used with a digital keyboard instrument that is connected to a computer through a USB port. It receives and interprets MIDI (Musical Instrument Digital Interface) inputs to determine how accurately a randomly generated passage of sheet music was played by the user. It does so by measuring pitch accuracy (how many correct notes were played) and rhythm accuracy (how many notes were played at correct times). A keyboard input scheme is also included in this build for testing purposes, which is detailed within the application's instructions screen.
